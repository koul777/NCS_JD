NCS JD Windows 휴대용 배포판
============================

1. ZIP 파일의 압축을 완전히 풉니다.
2. NCS_JD.exe를 실행합니다.
3. 브라우저가 자동으로 열리면 공고문과 선택적인 예시 양식을 올립니다.
4. 기본값인 "로컬 전용"은 외부 AI와 계정 로그인 없이 실행됩니다.
5. AI 정밀 탐색은 Claude Code 또는 Codex CLI 구독 로그인이 필요하며, API 키는 요구하지 않습니다.
6. examples 폴더의 공고문과 지원 HWPX 양식으로 먼저 시험할 수 있습니다.

필수 조건
---------
- Windows 10/11 64비트
- 기본 모드는 인터넷 연결 불필요(포함된 NCS 읽기 전용 데이터 사용)
- AI 정밀 탐색과 양식 보조 매핑만 인터넷 연결과 CLI 구독 로그인 필요
- NCS_JD.exe와 NCS_MCP 폴더의 상대 위치를 바꾸지 마세요.

예시 양식 처리
--------------
- PDF, HWP, HWPX 양식을 업로드할 수 있습니다.
- 빈 양식뿐 아니라 값이 채워진 HWP/HWPX/PDF 예시도 기존 예시값을 제거하고 새 값으로 재구성합니다.
- 표준 필드 별칭을 먼저 사용하고, 낯선 필드명은 CLI가 로그인되어 있으면 자동으로 보조 매핑합니다.
- 예시 양식을 실제로 반영하지 못하면 표준 양식으로 몰래 대체하지 않고 오류를 표시합니다.

보안과 데이터
-------------
- 두 서버는 127.0.0.1에만 열립니다.
- 포함된 NCS 데이터베이스는 읽기 전용으로 사용됩니다.
- 이 프로그램은 API 키나 토큰을 입력받지 않습니다. 자격은 공식 CLI 자체 저장소에만 남습니다.
- CLI에는 양식 필드명과 짧은 기존 예시값만 보내며 직무·NCS 근거 생성에는 사용하지 않습니다.
- 결과는 검토가 필요한 draft이며 채용 결정이나 공식 자격 인정 자료가 아닙니다.
- 로그: %LOCALAPPDATA%\NCS_JD\logs\launcher.log, ncs_mcp.log

NCS 데이터 제공기관: 한국산업인력공단
기준정보: https://www.data.go.kr/data/15128213/openapi.do
저작권정책: https://www.ncs.go.kr/blind/index.do

문제가 생기면 NCS_JD.exe --diagnostics 결과와 위 로그를 확인하세요.
